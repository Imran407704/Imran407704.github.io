# imran407704.github.io

Personal portfolio of **Imran Shaikh** — penetration tester, bug hunter and cybersecurity researcher.

Live: [imran407704.github.io](https://imran407704.github.io/)

## Stack

Static HTML, CSS and vanilla JavaScript. No build step, no frameworks, no trackers. Deployed with GitHub Pages from `main`.

## Structure

```
index.html          Home
privacy.html        Privacy notes
terms.html          Terms of use
404.html            Not found
css/style.css       Design system and layout
js/main.js          Rain canvas, reveals, command menu (Ctrl/Cmd + K)
assets/             Avatar, favicon, social preview
```

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Editing

- Copy and section order live in `index.html`.
- All colors, spacing and type scale are CSS custom properties at the top of `css/style.css`.
- Project cards are static; update star counts and copy by hand when a project changes.
- Replace `assets/og.png` if the social preview needs a refresh.
